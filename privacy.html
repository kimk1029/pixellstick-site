개인정보처리방침

시행일: 2026-11-26 · 앱: 픽셀스틱: 각인의 탑 (com.kimk1029.pixellstick) · 개발자: kimk1029

1. 현재 빌드의 데이터 처리

현재 0.3.0 빌드는 계정 가입을 요구하지 않으며 이름, 이메일, 연락처, 광고 식별자를 요청하지 않습니다. 광고·외부 분석·결제 SDK를 포함하지 않습니다. 게임 진행, 점수, 일일 도전 기록과 설정은 앱 전용 저장 공간에 저장됩니다. 플레이 기록을 개발자 서버로 전송하지 않습니다.

2. 인터넷 연결

앱은 게임 맵·밸런스 설정을 내려받기 위해 인터넷 권한을 사용하며 개발자의 GitHub Pages에 접속합니다. 이 요청에는 세이브나 플레이 기록을 포함하지 않습니다. 연결 처리 과정에서 호스팅 제공자가 IP 주소 등 접속 정보를 처리할 수 있습니다. 제공자의 처리는 GitHub 개인정보처리방침을 따릅니다. 네트워크 연결에 실패해도 앱에 포함되거나 기기에 저장된 설정으로 플레이할 수 있습니다.

3. 일일 랭킹

현재 빌드의 서버 랭킹은 서버 미연결 상태입니다. 일일 기록은 이 기기에만 저장되고 서버 등록 기능은 비활성화되어 있습니다. 향후 익명 식별자와 플레이 기록을 전송하는 서버 랭킹을 활성화할 경우, 전송 항목·보관 기간·삭제 방법을 본 방침과 앱에서 안내하고 이용자 동의 및 스토어 데이터 보안 신고를 반영한 뒤 제공하겠습니다.

4. 저장 정보 삭제

게임 진행·설정·점수·기기 내부 플레이 로그는 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다. 다른 기기로 자동 동기화하지 않습니다.

5. Google Play와 아동

앱 배포·테스트 참여·테스터 의견은 Google Play가 처리하며 Google 개인정보처리방침을 따릅니다. 이 앱은 아동을 대상으로 제작하지 않았습니다.

6. 변경과 문의

처리하는 데이터나 기능이 바뀌면 시행일과 이 문서를 갱신합니다. 문의: 프로젝트 문의 게시판. 게시판에 비밀번호나 개인 정보를 공개하지 마세요.

Privacy Policy (English)

No advertising, external analytics or payment SDK is included. Saves, settings, scores and daily run records remain in app-private device storage; gameplay records are not uploaded.

Internet access downloads map and balance configuration from the developer's GitHub Pages site. These requests do not include saves or gameplay records. The hosting provider may process connection information such as IP addresses under its privacy policy linked above. Offline play uses bundled or cached configuration.

The online leaderboard is not connected in this release. No ranking identifiers or results are transmitted. Before a future online ranking release, we will describe collected fields, retention and deletion, obtain in-app consent and update store data-safety disclosures. Local data can be removed by clearing app data or uninstalling. Google Play handles distribution and tester feedback under Google's privacy policy. The game is not directed at children. Contact: the project issues page above.
